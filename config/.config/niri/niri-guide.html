How to use niri (scrolling WM)

This guide matches your config: Super as Mod, Hyprland-style binds, laptop eDP-1 + HDMI on the right. Read the mental model first — the binds only make sense after that.

Mod = Super eDP-1 left HDMI-A-1 right

1. Mental model

Hyprland fills the screen with a grid of tiles. Niri is different: each workspace is an infinite horizontal strip of columns. The monitor is only a viewport — windows can live off the left or right edge until you scroll to them.

One monitor = viewport over a long strip ← scroll with Super+H / Super+L → [ term ][ browser ][ editor ][ notes ][ chat ] ▲ ▲ ▲ what you see on screen
Hyprland habitNiri reality
New window splits the current tile New window becomes a new column (often to the right)
Everything always visible Extra columns sit off-screen until you focus/scroll
Workspaces feel global Each monitor has its own vertical stack of workspaces
Master/stack or dwindle layout Columns side by side; stack windows inside a column

Two monitors

eDP-1 (laptop, left) HDMI-A-1 (right) ┌─────────────────────┐ ┌─────────────────────┐ │ workspace stack │ │ workspace stack │ │ WS1 ── strip → │ │ WS1 ── strip → │ │ WS2 ── strip → │ │ WS2 ── strip → │ │ WS3 ── strip → │ │ … │ └─────────────────────┘ └─────────────────────┘ ▲ ▲ Super+Shift+Left Super+Shift+Right └──────── focus which monitor ──┘

Rule of thumb

Think: left/right = scroll the strip, up/down = change workspace on this monitor, Shift+arrows = jump monitors.

2. Vocabulary

TermMeaning

Strip / scroll The infinite horizontal desktop of columns.

Floating Window leaves the strip (like Hypr float). Super+T
Consume / expel Pull a window into the neighboring column (stack) or push it out. Super+[ / ]
Maximize column Column takes full width (still tiled). Super+Shift+F

3. Day-1 practice path

Do these in order on the laptop screen. About 10 minutes.

  1. Open four terminals
    Press Super+Return four times. You should see columns appear; later ones may go off-screen to the right.
  2. Scroll the strip
    Super+H / L (or ← →). Focus moves column by column; the viewport follows.
  3. Stack two windows in one column
    Focus a window, press Super+[ or Super+] (consume/expel). Use Super+J/K to move focus up/down in the stack.
  4. Resize
    Super+- / Super+= width ±10%.
    Super+P cycles preset widths (⅓, ½, ⅔, full).
    In a stack: Super+Shift+- / = for height.
  5. Fullscreen vs maximize
    Super+F fullscreen · Super+Shift+F maximize column · Super+C center column.
  6. Workspaces
    Super+1…0 jump to workspace 1–10.
    Super+Shift+2 sends the focused window to workspace 2.
    Super+U / I workspace down / up.
  7. Apps you already know
    Rofi Super+Ctrl+Return · Browser Super+B · Files Super+E · Close Super+Q.
  8. Overview when confused
    Super+Tab — pick a workspace visually, then Esc or click.
  9. Hotkey overlay
    Super+Shift+/ (often Super+?) shows important binds.
  10. Two monitors — next section.

4. Two monitors — how it actually works

Important difference from Hyprland

On niri, each monitor has its own workspace list. Super+1 on the laptop is not the same space as Super+1 on the HDMI monitor. Focus a monitor first, then change workspaces on that monitor.

Focus which screen you’re on

ActionBind
Focus monitor to the left (laptop) Super+Shift+←
Focus monitor to the right (HDMI) Super+Shift+→

You can also just move the mouse onto the other screen (focus-follows-mouse is on).

Move a whole workspace to the other monitor

This is the main dual-monitor “send my layout over” tool:

ActionBind
Move current workspace to left monitor Super+Shift+Ctrl+←
Move current workspace to right monitor Super+Shift+Ctrl+→

Try this (dual-monitor drill)

  1. On laptop: open a terminal and a browser (two columns).
  2. Super+Shift+→ — focus HDMI.
  3. Open another terminal there — it belongs to HDMI’s strip.
  4. Super+Shift+← — back to laptop; your first strip is still there.
  5. On laptop, press Super+Shift+Ctrl+→ — the whole laptop workspace jumps to the HDMI monitor.
  6. Super+Tab if you lose track of where things went.

Moving a single window to the other screen

You don’t have a one-key “send window to other monitor” bind. Use either:

  1. Focus other monitor first, open the app there, or
  2. Put the window on a workspace (Super+Shift+N), then move that workspace to the other monitor (Super+Shift+Ctrl+arrows), or
  3. Focus the other monitor and use Overview / open fresh windows there.

5. Practical recipes

Coding

  • Laptop: editor column (maximize with Super+Shift+F).
  • HDMI: browser / docs / terminal strip; scroll with H/L.
  • Jump screens with Super+Shift+arrows without rearranging windows.

Reference on the side

  • On one monitor: editor at ~⅔ (Super+P until wide).
  • Second column: docs/terminal at ~⅓.
  • Need a third app? Open it — it becomes column 3 off-screen; scroll when needed.

Floating tools

  • Clipboard: Super+Shift+V (clipse, floating).
  • Volume UI: Super+A (pwvucontrol, floating).
  • Spotify: Super+Shift+S (floating).
  • Manual float toggle: Super+T.

Focus mode / gaming

  • Super+F1 gamemode (disables animations on niri).
  • Super+F fullscreen the game.
  • Super+Shift+P power off monitors (wake with input).

7. “I’m lost” emergency kit

  1. Super+Tab — Overview. Find the workspace with your windows.
  2. Super+Shift+arrows — Are you on the wrong monitor?
  3. Super+H/L — Scroll; the window may be off-screen on the strip.
  4. Super+Shift+/ — Hotkey overlay.
  5. Super+Ctrl+Return — Rofi; open a fresh terminal to reorient.
  6. Still stuck? Open this file again or check config at ~/.config/niri/config.kdl.

8. Common gotchas

  • “My window vanished.” It’s probably still open, just off the edge of the strip. Scroll or use Overview.
  • “Why won’t it split like Hypr?” Niri doesn’t dwindle-split. Use a new column, or stack with [/].
  • “Super+1 did the wrong thing.” You’re on the other monitor’s workspace 1. Focus the right monitor first.
  • Floating apps (clipse, spotify, volume) ignore the strip until unfloated.
  • Closing the last window doesn’t always “reset” scroll position the way you expect. Open a new window or switch workspace.
  • New windows default to half width in your config — use Super+P or maximize.
